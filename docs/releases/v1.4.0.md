# Shutter Cove 1.4.0 · Light & Color Studio

## English

Open a JPEG's details and choose **Color & edit**:

- Interactive Tone RGB, Red, Green and Blue curves, plus Temperature and Tint curves for separate shadow, midtone and highlight offsets. Click to add nodes; drag, type values or use arrow keys; delete nodes and reset individual channels.
- An interactive complementary color reference sits beside the curves.
- **AI Skin Radiance** analyzes skin-like colors entirely on your device. Adjustable strength, manual skin sampling and a mask preview support a restrained midtone lift and cast reduction while retaining texture. No AI model, account or upload is used; similar-colored backgrounds can also be selected.
- Before comparison, undo / redo, zoom and pan, and existing crop / rotation / mosaic tools share one editor. Full working-resolution export uses the same color analysis as the background preview and a lossless in-memory handoff. Closing an unsaved editor leaves no intermediate photo files.
- English and Chinese controls, readable font scaling, and resizable desktop layouts. JPEG replacement still requires confirmation; CR3 files are untouched.

[Guide](https://github.com/Undefeated-man/ShutterCove/blob/main/docs/color-studio.md) · [Synthetic interface screenshot](https://github.com/Undefeated-man/ShutterCove/blob/main/docs/screenshots/color-studio.png)

Install the matching Apple Silicon / Intel DMG or ZIP, or Linux x64 AppImage / deb. Check downloads against the same release's `SHA256SUMS.txt`. Mac packages are ad-hoc signed and are not Apple-notarized; see the [installation guide](https://github.com/Undefeated-man/ShutterCove/blob/main/docs/mac-install.md). Existing favorites, tags, settings and application identity are preserved. This editor adjusts rendered JPEGs, not RAW sensor data; very large sources are bounded to a safe working canvas and exported images do not retain source EXIF.

## 简体中文

打开 JPEG 的详情，点击 **“调色与修图”**：

- 新增明暗 RGB、红、绿、蓝曲线，以及色温、色调曲线；可分别调整暗部、中间调与亮部。点击加点、拖动、数值输入、方向键微调、删除节点和通道重置均可使用。
- 曲线旁加入可交互的互补色盘参考。
- **AI 一键通透** 使用本地色彩算法，自适应提亮肤色中间调、适度收敛偏色，保留纹理；可调整强度、取样肤色、查看调整范围。无需模型、账户或上传；相近颜色背景也可能被识别。
- 对比调色前、撤销 / 重做、放大与拖动查看细节，以及裁剪、旋转、马赛克整合在同一编辑器。后台预览与完整工作尺寸导出共用分析参数，无损内存传递避免中间 JPEG 重压。放弃编辑不会留下中间照片文件。
- 支持中英文、字体大小设置及可调整窗口；覆盖 JPEG 仍需确认，CR3 原片保留。
