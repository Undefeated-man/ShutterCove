## 简体中文

**当前支持 JPEG 与 Canon CR3，RAW 支持目前限于 CR3。** CR3 使用相机内嵌预览，不提供 RAW 显影。

### 详情缩放与平移

详情默认保持比例、整张适配窗口。按住 **Option（Mac）/ Alt** 使用滚轮缩放，放大后拖拽平移，最多放大到适合窗口大小的 16 倍。点击“适合窗口”或双击图片恢复默认视图。**100% 是相对于适合窗口大小，并非原图像素 1:1。**

JPEG 与对应 CR3 继续上下配对显示，各自保留编辑器入口。CR3 放大的是内嵌预览，清晰度受预览分辨率限制；这些浏览操作不修改原片。

普通滚轮继续滚动详情；预览获得焦点时可按 + / − 缩放，按 0 复位。两个格式的预览独立缩放，切换照片或调整预览区域大小时恢复适配。

### 更新与已有资料

Mac 用户先退出旧版，再将新版 App 拖入 Applications 并替换，之后从 Applications 启动。相同系统用户及应用标识继续使用原有本地设置、标签与收藏，不需要重新复制照片。首次引导、按需预览缓存、选片与 SD 卡整理功能保留。

## English

**Currently supports JPEG and Canon CR3; RAW support is limited to CR3.** CR3 browsing uses the camera's embedded preview, without RAW development.

### Detail zoom and pan

Photo details initially fit the complete image to the window while preserving its aspect ratio. Hold **Option (Mac) / Alt** while scrolling to zoom, then drag the enlarged image to pan, up to 16 times the fitted size. Choose “适合窗口” (Fit to window) or double-click the image to reset. **100% is relative to the fitted view, not a 1:1 original-pixel scale.**

JPEG and corresponding CR3 previews remain vertically stacked, each with editor handoff controls. CR3 zoom enlarges its embedded preview, so clarity depends on that preview's resolution. These viewing operations do not modify original photographs.

Ordinary scrolling still scrolls the detail view. With the preview focused, use + / − to zoom and 0 to reset. The two previews zoom independently; changing photographs or resizing the preview area restores the fitted view.

### Updating and existing data

On Mac, quit the older version, drag the new app into Applications, choose Replace, and launch it from Applications. The same system account and application identifier continue using existing local settings, tags, and favorites without copying photographs again. The first-use guide, on-demand preview cache, selection tools, and SD organization remain available.

Packages include DMG and ZIP for Apple Silicon and Intel macOS, plus AppImage and deb for Linux x64. Verify downloads with the same-version `SHA256SUMS.txt`.

On 2026-10-12, the source zoom regression passed 667 assertions at 900 × 680 and 661 at 1440 × 960, totaling 1,328. The existing detail-fit regression passed 233 assertions at each size. The final local macOS arm64 package passed 1,198 assertions across sixteen launches and 24 independent gallery assertions, totaling 1,222. Actual file copies and original-file hashes, JPEG export, persisted settings and guide completion, and recoverable SD journals were verified. Strict signature verification, DMG integrity, and packaged privacy checks passed. [Three-platform CI](https://github.com/Undefeated-man/shiguang-isle/actions/runs/38157899742) succeeded for macOS arm64, macOS x64, and Linux x64 builds and package regressions; each platform passed 1,222 assertions and actual disk-result checks. An actual Mac upgrade preserved existing settings and library metadata; the installed Applications copy appeared as a single searchable app and launched normally, with detail zoom and reset verified in production. Draft assembly succeeded. All six installers and the checksum file are uploaded and nonempty; all six SHA-256 entries match GitHub asset digests, and the checksum file's own digest also matches.
