# 拾光屿 v1.0.3 / Shiguang Isle v1.0.3

**专为拍摄 RAW 的单反与微单摄影用户量身定制的本地相册。**

**A local photo library built specifically for DSLR and mirrorless photographers who shoot RAW.**

## 简体中文

拾光屿围绕相机摄影的整理流程设计，从 SD 卡导入、RAW / JPEG 配对浏览、精选整理，到修图交接与作品导出。**当前支持 JPEG 与 Canon CR3，RAW 支持目前限于 CR3。**

- **RAW / JPEG 配对选片：** 对应照片一起浏览，两种格式均可交给修图软件；macOS 支持 Photoshop / Lightroom，Linux 可配置本机编辑器。
- **轻量预览与高效整理：** 按需加载、预读和可清理的限额缓存，浏览不复制完整原片；结合日期、色系、主题、标签与按需相似搜索找到作品。
- **原片与精选一起管：** SD 卡照片按日期导入，跨目录选片后一键复制并可选携带 CR3；精品同步将所选 SD 卡中未选的 JPEG / CR3 先移入可恢复的待删文件夹，方便核对。

### v1.0.3 更新

图库的筛选、多选与排序栏在照片滚动时保持在顶部。无需回到页面开头，即可调整日期、色系、主题与标签，改变排序或操作已选照片。

工具栏随窗口大小和字号自适应，照片定位为实际工具栏高度预留空间；日期时间轴仍用于快速定位当前筛选结果。打开、关闭日历或菜单以及确认选项后，返回焦点保持当前滚动位置，避免图库突然回到顶部。

原片、收藏、标签与主题保持不变。浏览使用可清理的轻量预览缓存，不创建完整原片副本。

安装包提供 Apple Silicon / Intel macOS 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb。下载后可用 `SHA256SUMS.txt` 核对完整性。macOS 使用 ad-hoc 签名，未进行 Apple 公证。

顶部固定交互已在原生 Electron 的常规与小窗口合成图库中分别通过 40 项断言，覆盖 150% 字号、深滚动、跨分页日期定位、筛选和多选操作，以及日历 / 菜单交互后的滚动位置保持。本地 macOS arm64 最终安装包通过 189 项完整烟雾测试和 24 项独立图库测试，共 213 项；实际复制、原片哈希、设置与可恢复 SD 同步核对通过，签名、DMG 与 1399 个打包文件的脱敏检查通过。[三平台 CI 与安装包装配](https://github.com/Undefeated-man/shiguang-isle/actions/runs/38148076016) 已全部成功；六个安装包名称、大小及 GitHub asset SHA-256 均已核对，与 `SHA256SUMS.txt` 全部一致。

## English

Shiguang Isle follows the camera photography workflow, from SD card import and paired RAW / JPEG browsing to favorite selection, editor handoff, and collecting photographs for delivery. **Currently supports JPEG and Canon CR3; RAW support is limited to CR3.**

- **Select RAW / JPEG pairs together:** Browse matching files together in the same detail view and hand either format to an editor. Use Photoshop / Lightroom on macOS or configure a local editor on Linux.
- **Lightweight previews and efficient organization:** On-demand loading, prefetching, and a bounded, removable cache avoid full original copies for browsing. Find photographs by date, color, theme, tags, or on-demand similarity search.
- **Manage originals and favorites:** Import SD card photographs by date, copy selections across folders with optional CR3 files, and synchronize favorites by first moving unselected JPEG / CR3 files on the chosen SD card into a recoverable pending-deletion folder for review.

### What's new in v1.0.3

The gallery's filtering, selection, and sorting toolbar now stays at the top while photographs scroll. Adjust dates, colors, themes, and tags, change the order, or act on selected photographs without returning to the beginning.

The toolbar adapts to the window and font size. Photo navigation reserves its actual height, while the date timeline continues to jump through the current filtered results. Returning focus after opening or closing the calendar or a menu, or confirming an option, preserves the current scroll position instead of jumping to the top.

Originals, favorites, tags, and themes remain unchanged. Browsing uses removable lightweight previews rather than full original copies.

Packages include DMG and ZIP for Apple Silicon and Intel macOS, plus AppImage and deb for Linux x64. Verify downloads using `SHA256SUMS.txt`. macOS packages use ad-hoc signatures and are not Apple-notarized.

The sticky controls passed 40 assertions in both regular and compact native Electron synthetic libraries, covering 150% font size, deep scrolling, cross-page date navigation, filtering, selection, and preserved scroll position after calendar or menu interactions. The final local macOS arm64 package passed 189 smoke assertions and 24 independent gallery assertions, totaling 213. Production copies, original hashes, persisted settings, and recoverable SD synchronization were verified, along with its signature, DMG, and privacy checks of 1,399 packaged files. [Three-platform CI and package assembly](https://github.com/Undefeated-man/shiguang-isle/actions/runs/38148076016) succeeded. All six installer names, sizes, and GitHub asset SHA-256 digests were checked; every digest matches `SHA256SUMS.txt`.
