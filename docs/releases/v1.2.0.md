# Shiguang Isle v1.2.0 · English and Chinese

A desktop photo library for DSLR and mirrorless photographers shooting JPEG / Canon CR3, with collage posters and GIF / meme creation.

- **Choose your language first.** New installations start in English and show an English / Chinese choice before the usage guide. Existing Chinese profiles retain Chinese after upgrading.
- **Switch instantly.** Settings → Interface language changes the entire app between English and Simplified Chinese and remembers the choice after restarting. The gallery, calendar, photo details, collage and GIF studios, update controls, and native file dialogs are localized.
- **Keep your work.** Switching preserves favorites, tags, the photo index, open editing sessions, poster composition, photo order, zoom, and unsaved titles or captions. It never translates your filenames, themes, tags, or photographs.
- **Read in four languages.** The default README is English, with an English / Chinese introduction and English, Chinese, Japanese, and Korean guides. Japanese and Korean are documentation translations; the app currently supports English and Simplified Chinese. More interface languages may be added according to demand.
- **Discover the creative tools.** The introduction highlights per-photo collage adjustments, original-ratio magazine posters, freely movable wooden-board photographs, and GIF / meme creation with filmstrip ordering and speech bubbles.

Download `mac-arm64.dmg` for Apple Silicon, `mac-x64.dmg` for Intel, or the Linux x64 AppImage / deb. Mac ZIP packages support the app's in-place updater. Verify the same release's `SHA256SUMS.txt`. macOS builds use ad-hoc signatures and are not Apple-notarized; see the [Mac installation guide](https://github.com/Undefeated-man/shiguang-isle/blob/main/docs/mac-install.md) if Gatekeeper blocks first launch.

Updates retain local favorites, tags, and settings and replace the existing installation in place. Original photos remain in their selected folders. Screenshots contain synthetic artwork only.

# 拾光屿 v1.2.0 · 中英界面

为拍摄 JPEG / Canon CR3 的单反与微单摄影用户设计的桌面相册，支持拼图海报、GIF 和表情包创作。

- **首次打开先选语言。** 全新安装默认英文，先选择 English / 中文，再进入使用引导；已有中文资料升级后保留中文。
- **一键切换并记住选择。** 在“设置 → 界面语言”即时切换简体中文与英文；覆盖相册、日历、详情、拼图、GIF、更新面板及原生文件对话框。
- **保留你的创作。** 切换时保留收藏、标签、索引、未保存的构图、照片顺序、缩放、标题和字幕，不改变文件名、主题、标签与原片。
- **四种语言说明。** 默认 README 为英文主体，安装前介绍为中英双语，顶部 Language 提供中、日、韩、英说明入口。日韩页面说明当前 App 仅支持中英界面，后续按需求增加语言。
- **创作亮点更清楚。** 介绍补充单张拼图构图、原比例杂志海报、自由移动与叠放照片的木质展示板，以及胶片排序、文字气泡与 GIF / 表情包。

Apple Silicon 下载 `mac-arm64.dmg`，Intel 下载 `mac-x64.dmg`；Linux x64 下载 AppImage 或 deb。Mac ZIP 可用于应用内更新。请核对同版本的 `SHA256SUMS.txt`。macOS 包为 ad-hoc 签名、未经过 Apple 公证，首次打开可能需要按 [Mac 安装说明](https://github.com/Undefeated-man/shiguang-isle/blob/main/docs/mac-install.md) 允许打开。

更新保留收藏、标签与设置，并在原安装位置替换。原照片留在所选目录。所有公开截图使用合成画面。
