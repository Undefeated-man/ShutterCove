## 简体中文

拾光屿围绕 SD 卡导入、JPEG / RAW 配对选片、精选整理与修图交接设计。**当前支持 JPEG 与 Canon CR3，RAW 支持目前限于 CR3。** CR3 浏览使用相机内嵌预览，不提供 RAW 显影。

### v1.0.4 更新

新增五步首次使用引导，介绍本地 JPEG / CR3 相册、打开相册或 SD 卡导入、筛选收藏标签、修图分享和 SD 卡预览整理。新用户首次正常启动时自动显示；跳过或完成后保存状态，后续启动不再弹出。已有相册配置的用户升级不中断，可在“相册设置 → 重新查看使用引导”重看。

最后可选择关闭引导开始浏览，或打开照片文件夹选择器。引导不会自动整理照片；← / → 可切换步骤，支持键盘焦点导航、小窗口与放大字号。JPEG 可简单编辑，CR3 使用内嵌预览并交给外部编辑器；macOS 支持 Adobe 交接，Linux 可配置本机编辑器。

浏览不创建完整原片副本；缩略图与内嵌预览使用有容量上限、可清理的缓存。照片导入、编辑、复制、删除和 SD 同步仍按所选操作执行。

安装包提供 Apple Silicon / Intel macOS 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb。使用 `SHA256SUMS.txt` 核对下载完整性。macOS 使用 ad-hoc 签名，未进行 Apple 公证。

源码引导在两个窗口各通过 109 项断言，完成状态的迁移和写盘失败检查也已通过。本地 macOS arm64 安装包通过 298 项完整测试和 24 项独立图库测试，共 322 项。完成状态真实保存并经两次进程重启验证；合成照片复制、原片哈希、JPEG 输出与可恢复 SD 同步均通过。签名、DMG 和 1400 个打包文件的脱敏检查通过。以上仅为本地验证，不代表三平台 CI 或公开发布；此版本由后续 v1.0.5 取代。

## English

Shiguang Isle follows the workflow of SD card import, paired JPEG / RAW selection, favorites, and editor handoff. **Currently supports JPEG and Canon CR3; RAW support is limited to CR3.** CR3 browsing uses the camera's embedded preview rather than RAW development.

### What's new in v1.0.4

A five-step first-use guide introduces the local JPEG / CR3 library, opening folders or importing from SD, filters and favorites, editing and sharing, and reviewing SD organization. It opens on a new user's first normal launch. Skipping or finishing saves completion; later launches do not show it automatically. Existing users with a configured library are not interrupted on upgrade. Reopen it through Album Settings → View usage guide again.

The last step can close the guide or open the photo folder picker. It does not organize photographs automatically. Arrow keys navigate the steps, with keyboard focus support and layouts for compact windows and larger fonts. Simple editing applies to JPEG; CR3 uses embedded previews and external editors. Editor handoff uses Adobe apps on macOS or a configured local editor on Linux.

Browsing does not create full original copies. Thumbnails and embedded previews use a bounded, removable cache. Imports, editing, copies, deletion, and SD synchronization continue to follow the selected operation.

Packages include DMG and ZIP for Apple Silicon and Intel macOS, plus AppImage and deb for Linux x64. Verify downloads using `SHA256SUMS.txt`. macOS packages use ad-hoc signatures and are not Apple-notarized.

Source guide tests passed 109 assertions in each of two window sizes; state migration and write-failure handling were also verified. The local macOS arm64 package passed 298 smoke assertions and 24 independent gallery assertions, totaling 322. Completion was saved to disk and verified across two process restarts. Synthetic copies, original hashes, JPEG output, and recoverable SD synchronization passed, along with signature, DMG, and privacy checks of 1,400 packaged files. These are local results, not proof of three-platform CI or public publication; v1.0.5 supersedes this version.
