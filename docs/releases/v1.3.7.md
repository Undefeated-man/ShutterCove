# Shutter Cove v1.3.7 · Many folders, one library

A desktop JPEG / Canon CR3 photo organizer and creative studio for DSLR and mirrorless photographers, available for macOS and Linux.

- **A persistent library across directories.** Add separate photo folders to the index without replacing earlier albums. Choose a default theme; All themes shows the complete registered library. Settings can add or remove indexed folders. Removal preserves originals, favorites and tags, and unavailable external folders remain registered for reconnection.
- **Imports you can see.** Preparation, capture-information reading, copying and indexing publish progress above the scrolling gallery. Completed imports immediately populate and open their theme. A source already inside its target theme is indexed in place; it is no longer rejected or copied again. Sources within an archive no longer deduplicate against themselves. Empty or entirely duplicate imports do not create phantom themes.
- **Automatic updates, on by default.** Turn them off in Settings. Supported writable Mac apps and AppImages download and verify stable releases, wait for photo work, editing/settings/detail dialogs and selection to finish, then show a 10-second idle countdown and update in place. New work delays the restart. Favorites, tags, settings and the existing application location are retained. Linux deb updates check and notify; installing still requires explicit system authorization. Manual Download only stays manual.

Download the matching Apple Silicon / Intel DMG or Linux x64 AppImage / deb from [official Releases](https://github.com/Undefeated-man/ShutterCove/releases), and verify with this version's `SHA256SUMS.txt`. Mac installers are ad-hoc signed and not notarized; see the [Mac installation guide](https://github.com/Undefeated-man/ShutterCove/blob/main/docs/mac-install.md). Compatibility package filenames retain `Shiguang-Isle-` and contain `Shiguang Isle.app`. Existing installations keep their identity and local data.

- **多个目录，一份持久相册索引。** 新增目录保留旧相册，主题负责当前展示，“全部主题”浏览完整索引。设置可添加、移除目录及选择默认主题；移除只影响索引，原片、收藏与标签保留。外置盘断开时保留目录，重新连接后刷新恢复。
- **修复导入后看不到照片和主题。** 准备、拍摄信息、复制与索引阶段都有顶部进度，滚动后仍可看见。完成立即切到导入主题；来源已是同名目标主题时原位纳入，不再错误拒绝或重复复制。回忆目录内的来源不会再把自己当重复文件；空来源、全部重复时不创建空主题。
- **默认开启自动更新。** 设置可关闭。可写位置的 Mac App 与 AppImage 自动下载并校验正式新版，等待照片任务、编辑/设置/详情窗口和多选结束，再显示 10 秒空闲倒计时并原位更新。有新操作就延期，保留收藏、标签、设置和原安装位置。Linux deb 仍需用户主动授权系统安装；手动“仅下载”不会自动重启。
