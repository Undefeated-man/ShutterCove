# Shutter Cove v1.3.8 · Smoked glass, quieter photographs

A desktop JPEG / Canon CR3 photo organizer and creative studio for DSLR and mirrorless photographers, available for macOS and Linux.

- **A refined two-tone workspace.** A smoked sage, frosted sidebar anchors navigation; warm-white glass and restrained shadows keep the main gallery light. Photo cards use a neutral ivory surface, and both gallery and cover photographs retain their original colors.
- **Clearer navigation and details.** Consistent outline icons replace mixed symbols. The selected theme stays highlighted in the sidebar, including after import or restoring the default theme; resetting filters clears it. Softer menu, calendar and selection surfaces share the same material palette.
- **Readable, adaptable controls.** Dark-sidebar text is checked against both light and dark backdrops. Existing Chinese / English, font-size settings, compact windows, keyboard controls and reduced-motion behavior are retained. Reduced-transparency and unsupported-blur fallbacks use opaque surfaces. Blur stays on workspace surfaces rather than adding filters to every photo card.

Multi-directory indexing, automatic in-place updates, favorites, tags, creative posters and GIF / meme tools remain available. The update preserves local library records and settings. Download the matching Apple Silicon / Intel DMG or Linux x64 AppImage / deb from [official Releases](https://github.com/Undefeated-man/ShutterCove/releases), and verify with this version's `SHA256SUMS.txt`. Mac installers are ad-hoc signed and not notarized; see the [Mac installation guide](https://github.com/Undefeated-man/ShutterCove/blob/main/docs/mac-install.md).

## 中文

- **烟灰绿侧栏＋暖白主区。** 侧栏采用深色磨砂玻璃，主页面保持轻盈通透，阴影与边缘高光更克制。照片卡片改为接近中性的暖白底，缩略图与相册封面保持照片原色。
- **导航和信息层次更清楚。** 统一线条图标，当前主题在侧栏高亮；导入完成、恢复默认主题和重置筛选时同步更新。日历、筛选菜单和多选浮栏采用一致的玻璃材质与配色。
- **兼顾可读性、窗口大小和浏览速度。** 深色侧栏文字在明暗背景下检查对比度，保留中英文切换、字体设置、窄窗口、键盘操作及减少动态效果支持。减少透明度或浏览器不支持模糊时采用实色表面；照片卡片不增加额外模糊层。

多个目录统一索引、默认主题、自动原位更新、收藏标签、拼图海报与 GIF / 表情包功能继续保留。升级保留相册记录与设置。当前 App 支持英文与简体中文，日韩指南仍为文档翻译。
