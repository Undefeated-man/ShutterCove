# 拾光屿 v1.0.5 / Shiguang Isle v1.0.5

**专为拍摄 RAW 的单反与微单摄影用户量身定制的本地相册。**

**A local photo library built specifically for DSLR and mirrorless photographers who shoot RAW.**

## 简体中文

拾光屿围绕 SD 卡导入、JPEG / RAW 配对选片、精选整理与修图交接设计。**当前支持 JPEG 与 Canon CR3，RAW 支持目前限于 CR3。** CR3 浏览使用相机内嵌预览，不提供 RAW 显影。

### 首次使用引导

五步引导介绍本地相册、打开相册或 SD 卡导入、筛选收藏标签、修图分享，以及先预览再确认的 SD 卡整理。新用户首次正常启动自动显示；成功跳过或完成后保存状态，后续启动不再弹出。已有相册配置的用户升级不中断，可在“相册设置 → 重新查看使用引导”重看。

最后可关闭引导或打开照片文件夹选择器。引导不会自动整理照片；支持方向键、焦点导航、小窗口与放大字号。JPEG 可简单编辑，CR3 可交给外部编辑器；macOS 支持 Adobe 交接，Linux 可配置本机编辑器。

### 大照片详情显示

修复高分辨率横图、竖图及宽幅图在详情预览中被裁断的问题。JPEG 与 CR3 内嵌预览保持比例、整张适配预览框，预览区随窗口高度调整。配对预览继续上下显示，可滚动访问下方图片与编辑器按钮，底部上一张 / 下一张操作始终可用。

浏览不创建完整原片副本；缩略图和内嵌预览使用有容量上限、可清理的缓存。安装包提供 Apple Silicon / Intel macOS 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb，下载后可使用 `SHA256SUMS.txt` 核验。

详情源码回归已在 900 × 680 与 1440 × 960 窗口各通过 233 项断言，覆盖大尺寸横图、竖图、宽幅图和放大字号。2026-10-12，本地最终 macOS arm64 包十五次启动、531 项断言及独立图库回归 24 项全部通过，共 555 项；真实文件复制与原片哈希、JPEG 导出、设置持久化和可恢复 SD 整理均已核对。严格签名验证、DMG 完整性与包内脱敏检查通过。[三平台 CI 与草稿装配已成功](https://github.com/Undefeated-man/ShutterCove/actions/runs/38153762129)，每个平台的打包应用均通过 555 项断言和实际文件结果核对。六个安装包均已上传且非空，SHA-256 校验表六项与 GitHub 资产摘要全部一致，校验表自身摘要亦一致。

## English

Shiguang Isle follows the workflow of SD card import, paired JPEG / RAW selection, favorites, and editor handoff. **Currently supports JPEG and Canon CR3; RAW support is limited to CR3.** CR3 browsing uses the camera's embedded preview rather than RAW development.

### First-use guide

Five steps introduce the local library, opening folders or importing from SD, filters and favorites, editing and sharing, and reviewing SD organization. It opens on a new user's first normal launch. Successfully skipping or finishing saves completion; later launches do not open it automatically. Existing users with a configured library are not interrupted on upgrade. Reopen it through Album Settings → View usage guide again.

The last step can close the guide or open the photo folder picker. It does not organize photographs automatically. Arrow keys and focus navigation work with compact windows and larger fonts. Simple editing applies to JPEG; CR3 can be sent to an external editor. Use Adobe apps on macOS or a configured local editor on Linux.

### Large-photograph detail view

Fixes high-resolution landscape, portrait, and panoramic photographs being clipped in the detail preview. JPEG and CR3 embedded previews fit completely within the frame while preserving their aspect ratio, and the preview area adapts to the window height. Paired previews remain vertically stacked. Scroll to reach the lower image and editor buttons; previous / next controls stay available at the bottom.

Browsing does not create full original copies. Thumbnails and embedded previews use a bounded, removable cache. Packages include DMG and ZIP for Apple Silicon and Intel macOS, plus AppImage and deb for Linux x64, with `SHA256SUMS.txt` for download verification.

The source detail regression passed 233 assertions at each of 900 × 680 and 1440 × 960, covering large landscape, portrait, and panoramic photographs and larger fonts. On 2026-10-12, the final local macOS arm64 package passed 531 assertions across fifteen launches and all 24 independent gallery assertions, totaling 555. Actual file copies and original-file hashes, JPEG export, persisted settings, and recoverable SD organization were verified. Strict signature verification, DMG integrity, and packaged privacy checks passed. [Three-platform CI and draft assembly succeeded](https://github.com/Undefeated-man/ShutterCove/actions/runs/38153762129); each platform's packaged application passed 555 assertions and actual disk-result verification. All six installers are uploaded and nonempty; all six checksum entries match GitHub asset digests, and the checksum file's own digest also matches.
