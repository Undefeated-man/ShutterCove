# 拾光屿 v1.0.2 / Shiguang Isle v1.0.2

验收结果见 [验证记录 / Validation records](https://github.com/Undefeated-man/shiguang-isle/blob/main/docs/validation.md)。

## 简体中文

本次更新让条件筛选下拉菜单与日历的鼠尾草绿毛玻璃样式统一。长列表最多显示六项，可滚动或搜索选项，边缘以轻微渐隐保持清爽；支持方向键选择、Enter 确认与 Esc 关闭。

多选操作改为“复制到文件夹”，将不同子目录的 JPEG 平铺汇集到目标目录，可选择已有文件夹或在选择器中新建。可勾选同时复制 CR3，默认关闭；重名时唯一改名，同组 JPEG / CR3 共用名称。原片保留，支持进度、取消与结果查看；单张照片仍可在文件管理器中显示。

修复大型图库扫描结束后迟到的预览进度覆盖完整列表的问题，避免只剩前 120 张照片；扫描结束后保持全部结果。

照片仍在所选目录中，浏览不创建完整原片副本。此次界面更新不改变原片、收藏、标签或主题。

安装包提供 Apple Silicon / Intel macOS 的 DMG 与 ZIP，以及 Linux x64 的 AppImage 与 deb。下载后可用 `SHA256SUMS.txt` 核对完整性。macOS 使用 ad-hoc 签名，未进行 Apple 公证。

本地修复后的 macOS arm64 安装包已通过 149 项完整烟雾测试和 24 项独立图库测试。真实复制核对默认 JPEG、可选合成 CR3、重名与配对名称，副本和原片 SHA-256 一致；签名、DMG 和打包脱敏检查通过。正常图库及原生目标选择器中新建文件夹已在本机实际验证。三平台 CI 与公开发布仍待完成。

## English

This update brings filter dropdowns into the same sage-green frosted-glass style as the calendar. Long lists show up to six options at a time, with scrolling, option search, and subtle fades at the edges. Use arrow keys to select, Enter to confirm, and Esc to close.

Batch selection now offers “Copy to folder” to collect JPEGs from different subfolders into one flat destination. Choose an existing folder or create one in the picker. Optionally include CR3 files (off by default); collision names are unique and shared by each JPEG / CR3 pair. Originals stay in place, with progress, cancellation, and a result summary. Individual photographs can still be revealed in the file manager.

Fixes late preview-progress events replacing the complete results after a large-library scan, which could leave only the first 120 photographs visible. Completed scans retain the full result list.

Photographs remain in the selected folders, and browsing does not create full original copies. This interface update leaves originals, favorites, tags, and themes unchanged.

Packages include DMG and ZIP for Apple Silicon and Intel macOS, plus AppImage and deb for Linux x64. Verify downloads using `SHA256SUMS.txt`. macOS packages use ad-hoc signatures and are not Apple-notarized.

The rebuilt local macOS arm64 package passed 149 smoke assertions and 24 independent gallery assertions. Production copy checks cover JPEG defaults, optional synthetic CR3 bytes, collisions, and shared pair names, with matching hashes for copies and unchanged originals. Signature, DMG, and packaged privacy checks passed. Normal-library browsing and creating a folder in the native destination picker were also verified on the local Mac. Three-platform CI and public publication are still pending.
